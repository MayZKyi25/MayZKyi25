## Currently building

### 🧠 Transformer Language Model — In Progress

I am building a small transformer language model from first principles in PyTorch to deepen my understanding of modern LLM architecture and training.

My current implementation focuses on:

- Token and positional embeddings
- Causal self-attention and multi-head attention
- Transformer blocks and feed-forward networks
- Model training, validation, and loss evaluation
- Controlled text generation and experiment tracking

This project goes below the API layer and documents the engineering decisions, experiments, and lessons involved in building a working language model.

`Python` `PyTorch` `Transformers` `Deep Learning` `LLM Fundamentals`
